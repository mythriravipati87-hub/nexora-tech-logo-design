 Nexora Tech – Logo Design Project

 About the Project
Nexora Tech is a creative logo design project focused on building a modern and memorable visual identity for a technology brand.

 Project Objectives
- Explore multiple logo concepts.
- Create a modern, technology-inspired logo.
- Develop colour and black-and-white variations.
- Maintain consistent colours and typography.

 Tools Used
- Canva
- PNG image export

 Brand Identity
- Brand Name: Nexora Tech
- Tagline: Innovate • Build • Grow
- Industry: Technology & IT Solutions
- Design Style: Modern, creative, and colourful

 Colour Palette
- Blue: #4F8CFF
- Purple: #A855F7
- Pink: #FF6B9D
- Orange: #FFA94D

 Project Outcome
Created a modern logo with colour and black-and-white variations for digital branding and presentation.

 Skills Learned
Logo conceptualization, colour selection, typography, visual design, and brand identity.
